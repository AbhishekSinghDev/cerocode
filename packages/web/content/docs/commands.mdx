title: Commands
description: Every slash command available in the cerocode TUI.
---

Type `/` in the composer to open the command menu. It filters as you type;
navigate with <Kbd>↑</Kbd>/<Kbd>↓</Kbd> and run with <Kbd>Enter</Kbd>.

## Command reference

| Command | Description |
| --- | --- |
| `/new` | Start a new conversation |
| `/agents` | Switch between agents (BUILD / PLAN) |
| `/models` | View and change the current model |
| `/sessions` | View and manage your conversations |
| `/theme` | Change the application theme |
| `/login` | Sign in via your browser |
| `/logout` | Sign out of your account |
| `/upgrade` | Buy more credits |
| `/usage` | Open the billing portal in your browser |
| `/exit` | Quit the application |

## Notes

- The menu shows up to 8 matches at a time and supports mouse hover and
  click as well as keyboard navigation.
- <Kbd>Esc</Kbd> closes the menu without running anything.
- Commands only trigger when `/` is the first character — typing a `/`
  mid-sentence just types a slash.
